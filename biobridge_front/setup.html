Set up BioBridge

About 30 minutes from sign-up to your first attendance record in Odoo.

Before you start

  • An Odoo user in Attendances / Administrator (or HR Officer), with an API key: Odoo → Preferences → Account Security → New API Key.
  • For BioTime: its server URL and an admin login. For a standalone terminal: its IP address, reachable from BioBridge.
  • The timezone the devices themselves run in.

1 · Connect Odoo

In Settings → Odoo connection, enter the server URL (just the address — no /odoo or /web on the end), the database, login and API key, then press Test connection.

On a multi-company Odoo, a company list appears once the test succeeds; pick the company this connection should use. The same test switches on device tracking, so each attendance shows which terminal recorded it.

2a · Add a BioTime server

In Settings → Biometric connections, choose + Add connection → Platform server. Give it a name, the server URL, login, password and the server's timezone. Once it connects, press Import terminals to bring in every terminal BioTime manages, with its area.

2b · Add a standalone device

Choose + Add connection → Standalone device. Name it for where it hangs (Front door), add its location and IP address, and connect. BioBridge reads the serial number from the device and registers it in Odoo straight away.

Each later Test connection also adds any Odoo employees with a badge ID or PIN who aren't on the device yet, so new hires can enrol their fingerprint.

3 · Match badges

BioBridge matches each badge to an Odoo employee by barcode, then PIN, registration number and work email. Anything it can't match with certainty waits under Unmapped employees for you to pick — its attendance is held, not lost.

4 · Choose a pairing mode

In Settings → Pairing. Most sites never need to change the default.

Alternating

In, out, in, out by time. Right for devices with no IN/OUT keys — most of them.

State based

Trusts the device's IN/OUT key. Falls back to alternating if everything arrives as "Check In".

First / last

First punch of the day in, last out. Set when the day starts for night shifts.

Troubleshooting

Times are hours off. The device timezone on the connection is wrong — punches arrive with no offset.

"Already checked in" from Odoo. An existing attendance overlaps the new one, often one entered by hand. Fix it in Odoo, then press Retry on the punch in Activity.

A terminal's punches never arrive. Check it isn't disabled on the Terminals page.
